porest 의 색은 제품의 위계 · 상태 · 브랜드를 나타낸다. 체계는 **역할 색**과 **기본 색** 두 층이다.

## 역할 색

색마다 인터페이스에서 맡는 역할 — 주요 동작 · 오류 · 정보 같은 — 을 준다. 화면은 값이 아니라 역할 이름으로 색을 부른다.

- **접근성** — 글자와 그 글자가 놓이는 배경의 짝마다 WCAG AA 대비를 검사기가 잰다(본문 4.5:1 · UI 3:1). 한국 웹 접근성 기준(KWCAG 2.2)도 같은 식이다.
- **빈틈없는 갱신** — 값이 같아도 뜻이 다르면 따로 바꿀 수 있다. 오류 글자 색만 진하게 해도 오류 채움 버튼은 영향받지 않는다.
- **테마** — 역할마다 라이트 · 다크 값을 함께 둔다.


## 기본 색

브랜드 색 · 회색 · 의미 색 · 차트 색이다. 역할이 가리키는 값이고, 차트처럼 역할로 나타내기 어려운 자리에서는 직접 쓴다.


## SEED 와 다른 점

- 이름과 구조는 당근 SEED 를 따르고 값은 porest 색이다. SEED 는 대비를 APCA 로 맞추는데 porest 는 WCAG AA 가 규칙이라, SEED 값을 WCAG 로 재면 흐린 글자가 흰 바탕에서 3.42:1 로 못 미친다.
- 브랜드가 둘이다 — Desk 파랑 · HR 초록. 브랜드 역할은 브랜드마다 값이 다르고, 나머지 역할은 두 브랜드가 같다.
- SEED 의 팔레트는 **적응형**이다 — 같은 이름(`gray-100`)이 라이트 · 다크에서 알맞은 명도로 바뀐다. porest 의 기본 색은 모드마다 이름이 따로(`-light` · `-dark`)이고, 모드를 따라 바뀌는 것은 역할 색이다.
